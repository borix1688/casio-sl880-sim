# CASIO SL-880「ゲーム電卓」HTML 模擬器

> 🌐 線上部屬（啟用 GitHub Pages 後）：<https://borix1688.github.io/casio-sl880-sim/>

單檔、離線可跑。直接雙擊 `index.html`（或拖進瀏覽器）即可，不需要伺服器、不需要網路。桌機是「機身 + 說明面板」並排，手機／窄視窗自動切成直式單欄（LCD 與按鍵都是比例式的，會跟著縮）。

## 內容

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 模擬器本體：三段模式開關、10 位數 7 段 LCD、計算機鍵盤、Digital Invaders 遊戲、MG-880 旋律模式、面板說明與設定 |
| `selftest.js` | 用最小 DOM stub（含假 WebAudio）在 Node 裡把整支程式跑起來的自動測試 |

跑測試：

```powershell
node .\selftest.js
```

## 三種模式（機身上方的 MODE 滑動開關）

| 段位 | 行為 |
| --- | --- |
| `OFF` | 關機，LCD 全暗 |
| `♪` | **MG-880 旋律模式**（SL-880 沒有；見下節） |
| `CAL` | 電卓 + 遊戲 |

面板上的 `♪` 鍵（虛線框、標 EXTRA）會直接跳到旋律模式並演奏內建曲；`ON` 鍵可開關機。

## 遊戲規則（依官方型錄與 1981 年原型機公開資料）

- 按 **GAME** → 顯示最高分 → 顯示本局條件（16 個侵略者 / 30 發飛彈）→ 開打。
- **AIM** 切換砲台數字：`0→1→…→9→n→0`（`n` = UFO）。
- **FIRE** 發射；命中同數字者擊落，**沒中也扣一發飛彈**。
- 得分依擊落位置，越靠右越高：

| 位置（砲台往外） | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| Part 1 | 10 | 20 | 30 | 40 | 50 | 60 |
| Part 2 | 20 | 40 | 60 | 80 | 100 | — |

- **UFO(n)**：本回合累積擊落數字和為 10 的倍數時，**下一個**出現的侵略者變成 UFO，擊落 **+300**。
- 侵略者碰到砲台 → 掉一顆砲台（共 3 顆）。砲台用光、或 **30 發飛彈打完還沒清光 16 個** → GAME OVER。
- 清完 16 個進下一回合，速度變快；第 9 回合清完進 **Part 2**（從右邊第 2 格就出現、分數加倍）；Part 2 第 9 回合清完回到 Part 1 第 1 回合。

## MG-880 旋律模式

- **1 2 3 4 5 6 7** = ド レ ミ ファ ソ ラ シ（C4–B4）；**8 9 0** = 高一度的 ド レ ミ（C5–E5）。切到 `♪` 時鍵面會浮現音名。
- **♯ +/−** 切換升半音、**►** 取消；LCD 右下角的點會亮起來表示 ♯ 生效。
- **`♪` 鍵 = 演奏內建曲**《聖者的行進》（When the Saints Go Marching In），在任何模式下都能按。
- **`GAME` 鍵 = 切回 CAL 並直接開始遊戲**（預設）。
  - 實機 MG-880 在音楽モード下按 GAME 是「演奏內建曲」，不是開遊戲。要這個原始行為，請在面板設定勾選 **「♪ 模式下 GAME 鍵改為演奏內建曲」**。
  - 之所以預設反過來：照實機做的話，在 ♪ 模式下按 GAME 只會播音樂、不會離開音樂模式，用起來像卡住。
- 單音（單聲道方波），與壓電蜂鳴器一樣沒有和聲。

### 鍵盤

`G` GAME · `Z` / `←` AIM · `X` / `Space` FIRE · `0-9` `. + - * /` · `Enter` = · `Backspace` ► · `Esc` AC · `C` C · `M` MR

## 沒聲音怎麼辦（照順序檢查）

1. 面板上有一顆 **🔊 測試音效** 按鈕與 **音訊狀態** 指示：
   - 顯示 `已就緒 running` → 音訊正常，問題在裝置音量或靜音開關。
   - 一直停在 `suspended` → 瀏覽器還沒解鎖音訊，**點一下機身任一按鍵**即可（本模擬器已註冊 `pointerdown` / `touchstart` / `mousedown` / `keydown` 四種手勢自動解鎖）。
   - 顯示 `此瀏覽器不支援 WebAudio` → 換瀏覽器。
2. **iPhone / iPad 的側邊靜音鍵會把 WebAudio 一起靜音**——這是 iOS 的既知行為，任何網頁都無法用程式繞過，請撥到響鈴。
3. 確認**媒體音量**（不是鈴聲音量）已開大；面板也有音量滑桿（master gain）。
4. 從 GitHub Pages 讀到舊版時請強制重新整理：<kbd>Ctrl</kbd>+<kbd>F5</kbd>（手機可加 `?v=2` 之類的查詢字串繞快取）。

## 實作說明與已知差異

- **命中判定**：同一數字若場上有多個，先打掉**最靠近砲台**那一個。這是模擬器的判定，實機細節沒有原廠說明書可逐條核對（網路資料只說到「可瞄準任一位置的同數字者」）。
- **畫面欄位**：10 格 LCD 對應成「砲台 1 格 + 生命 3 橫線 1 格 + 方向箭頭 1 格 + 侵略者 6 格」，與型錄照片 `0E←76n51` 的排列一致；字型與段數是近似重繪。
- **旋律模式的鍵位對應沒有原廠手冊可查**：MG-880 的開關確實是「OFF / 音楽モード / 電卓＆ゲームモード」三段、音樂模式下按 GAME 會播《聖者が街にやってくる》（lsigame 記載），但ドレミ的實際鍵位與 ♯ 修飾是我補的近似配置。
- **GAME 鍵在 ♪ 模式下的行為刻意偏離實機**（預設開遊戲而非演奏曲子），理由見上一節；實機行為可在設定裡叫回來。
- **副顯示列**（LCD 下方那條 HUD）是本模擬器加的，實機只在遊戲前後與回合結束顯示分數。
- **速度**依 MG-880 移植 App 的量測值反推：第 1 回合約 7 秒、第 9 回合約 2.3 秒橫越畫面。面板速度滑桿可調。
- **音效**用 WebAudio 方波近似，非實機取樣；音訊需在使用者手勢中解鎖（行動瀏覽器限制），面板有狀態指示與測試音效按鈕。
- 實機說明書還有「依得分分級的ランク表」，我沒有可靠的分數門檻資料，所以沒做。
